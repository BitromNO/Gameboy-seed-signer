# Game Boy Seed Signer Plan

## Goal

Build a playful prototype for a Bitcoin seed signer that looks like a Game Boy cartridge and can display signing information in a simple flow.

## Phase 1

- generate mnemonic words
- derive a wallet path
- show public key info
- simulate a transaction signing flow

## Phase 2

- create a targeted ROM artifact with cartridge branding
- improve the menu and screen flow
- make the output more transaction-like

## Phase 3

- add safer offline signing concepts
- improve signing review logic
- evaluate realistic PSBT and transaction handling

## Notes

This is a prototype only. It is not meant to be secure or production-ready.
